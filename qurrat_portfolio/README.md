# Syeda Qurrat - Personal Portfolio

Responsive personal portfolio built with HTML5, CSS3, Bootstrap 5, and JavaScript ES6+.

## Sections
Home, About, Education, Skills, Projects, Certifications, Internships, Contact.

## Features
- Responsive Bootstrap layout
- Light/dark theme toggle
- Project filtering
- Real GitHub repository links
- Client-side form validation
- Simple CSS animations and hover effects
- Education cards without an inner scroll area
- Balanced five-card Skills layout
- Certifications and internship experience
- Accessible labels, semantic sections, alt text, and reduced-motion support

## Run
Open `index.html` in a browser.

- Footer with GitHub, HackerRank, and LeetCode links
